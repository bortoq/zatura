# Follow-up fixes for the independent audit of 8d441d4

## Confirmed ioctl metadata bypass

Removed the blanket ioctl allowance on fd 1/2. Production seccomp now calls
`seccomp_restrict_ioctl()`, shared with regression tests. It permits only
`TCGETS` and `TIOCGWINSZ` on stdout/stderr. Every other request receives the
filter default denial; the viewer uses `SCMP_ACT_KILL_PROCESS`. Closing and
reopening stdout/stderr cannot turn a filesystem mutation into an allowed call.
No assumption about Landlock IOCTL_DEV coverage of regular files is needed.

`sandbox-fds` closes and reopens both fd 1 and fd 2 after enforcement, then
requires FS_IOC_SETFLAGS, FS_IOC_SETVERSION, TIOCSTI, TIOCSWINSZ and TCSETS to
fail. It verifies unchanged contents, permissions and inode flags (when the
filesystem supports FS_IOC_GETFLAGS). A second fixture uses the viewer's fatal
default and requires SIGSYS for FS_IOC_SETFLAGS on each reused descriptor.
Terminal attribute/size reads remain usable, including under a real PTY.

## Maintenance and contract

Removed unused `landlock_restrict_write()`, its path-rule helper and declaration.
There is no remaining unsynchronized Landlock enforcement helper. The active
path still requires ABI 8 and TSYNC. SANDBOX.md enumerates the specific syscall
and ioctl restrictions rather than promising a universal metadata prohibition.
The X11 IPC and trusted compositor limitations remain explicit.

## Validation

- Full engine suite: 23 passed, zero failures, including X11 and Weston sandbox.
  Evidence: `build/engines/meson-logs/testlog.txt`.
- Native sandbox suite: 4 passed, 1 explicit SKIP, zero failures.
  Evidence: `build/native-sandbox/meson-logs/testlog.txt`.
- Real seccomp-only zatura-sandbox PDF smoke: Installed viewer PDF render: OK.
- Updated sandbox-fds regression under Docker PTY: passed, including terminal
  reads, errno-based denials and fatal-default descriptor reuse cases.
- Git diff whitespace check: passed.

The local host provides Landlock ABI 3, so the real ABI 8 thread test remains
unverified. A read-only GitHub runners query found no registered repository
runners; the existing manual ABI 8 workflow therefore cannot be run here with
its required self-hosted runner. A passing mock ABI-policy test is not a positive
kernel TSYNC result. Before a public release, provide that runner, execute the
runtime gate, and complete the existing package/portal release checks with a
new version/tag. This source fix does not publish a release.

Pre-existing GPU work is excluded from this audit commit.
